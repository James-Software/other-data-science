# Acalanes Data Fest

Redesigned landing page for the Acalanes Data Science Club hackathon:
blue, black, and white school theme with a 3D spinning Acalanes "A" hero.

Static site: `index.html` + `styles.css` + `coin.js` (vanilla WebGL, zero
dependencies) + `script.js`. Instagram
[@aca.datasci.club](https://instagram.com/aca.datasci.club) is the signup
path; event date, location, and registration are TBD.
